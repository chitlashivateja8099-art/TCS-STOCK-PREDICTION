# 📈 TCS Stock Price Prediction Using Machine Learning

## 📌 Project Title

**Stock Price Prediction**

## 📖 Project Description

Stock price prediction is the process of using historical stock-market data and machine learning techniques to estimate future stock prices.

In this project, historical **Tata Consultancy Services (TCS)** stock data is used to build machine learning models that predict the next trading day's closing price.

The project uses two machine learning algorithms:

1. Linear Regression
2. Random Forest Regression

The performance of both models is evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

The predicted values are compared with the actual stock prices using graphs.

> **Note:** This project is developed for educational and experimental purposes. Stock predictions are not guaranteed and should not be considered financial or investment advice.

---

# 🎯 Objectives

The main objectives of this project are:

- To collect historical TCS stock-market data.
- To understand and analyze stock-market data.
- To preprocess the dataset.
- To create features for machine learning.
- To predict the next trading day's closing price.
- To implement Linear Regression.
- To implement Random Forest Regression.
- To evaluate and compare the models.
- To visualize actual and predicted stock prices.
